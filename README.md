# Mighty Device app — releases

The installers of the Mighty Device app, the small desktop app that runs the Mighty device daemon on a person's own PC and shows what it holds: whether the PC is paired and online, the runs it holds, and the decisions waiting on the person.

Each release carries `Mighty-Device-Setup.exe` (Windows) and `Mighty-Device.dmg` (macOS). The source lives in the Mighty console's repository; this repository holds binaries only.
